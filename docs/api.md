# 资料服务接口

服务只在本机提供 JSON，响应编码为 UTF-8。查询接口不修改资料。

| 方法和路径 | 当前行为 |
| --- | --- |
| `GET /health` | 数据指纹和存活状态 |
| `GET /tables` | 表、字段类型和记录数 |
| `GET /tables/{name}?offset=0&limit=50` | 原始资料分页；偏移非负，每页一至五百行 |
| `GET /view` | 当前领域经营资料摘要 |
| `GET /profiles` | 数值字段的观察数、缺失数、中位数及绝对中位差 |
| `GET /bunching?threshold=&window=&exclusion=&model=` | 包邮门槛聚集研究；省略 `threshold` 时研究全部已生效门槛 |
| `POST /cases` | 保存研究备注和当前完整资料副本；返回新记录 |
| `GET /cases` | 研究记录索引 |
| `GET /cases/{id}` | 校验完整性并回读记录 |

## 门槛聚集研究

`GET /bunching` 的参数都是可选的：

* `threshold`：观测过的门槛金额（十进制字符串）。省略时逐个报告全部门槛。给定
  一个从未在 `shipping_rules` 中生效的门槛时返回 `status: out_of_support`，不产生
  任何凑单量或收益数字。
* `window`：门槛两侧的研究窗口（元，默认 12）。
* `exclusion`：反事实拟合时剔除的门槛带（元，默认 20，须不小于 `window`）。
* `model`：首选反事实，取 `composition`（默认，全样本边际构成模型，保守下限）、
  `composition_excluded`（窗口外边际，上界）、`poisson1`、`poisson2`（连续平滑对照）。

每个门槛的结果包含金额刻度、商品价格×数量结构、运行变量口径、聚集量估计、规格曲线
（窗口×排除区间×拟合选择）、规则外虚假门槛、留出区间与跨门槛期留出反事实、跨期对照、
经营核对与识别结论。识别结论只有 `supported` 与 `insufficient` 两种；`insufficient`
表示至少一项诊断与“有凑单”不相容（例如门槛下方超额不显著、同一刻度在另一门槛期同样
密集、规则外虚假门槛给出同量级超额、或跨期留出反事实下超额消失）。

来源表未找到返回 404；字段或分页无效、研究参数无效返回 400。默认监听 127.0.0.1:8080。
服务只提供资料浏览、数值探索、门槛聚集研究与研究备注，不将保存备注视为已完成分析，
也不把聚集量解释为新增销售或收益承诺。

创建研究备注的字段为 `label`、`options` 和 `notes`，分别是名称、参数对象与说明文字。
名称一至一百二十字，后两项可省略。不接受其他字段，不允许覆盖旧记录。记录 ID 由服务
生成。资料指纹由原始数据和结构共同形成，不表示计算结果的统计可信度。
